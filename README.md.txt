# E-commerce Sales Analysis (SQL Project)

## Overview
This project analyzes e-commerce data using SQL.

The goal is to understand:
- revenue
- customer behavior
- product performance
- returns

## Tables Used
- customers
- orders
- order_items
- products
- returns

## Key Analysis
- Total Revenue
- Total Orders
- Average Order Value (AOV)
- Revenue by Month
- Refunds and Net Revenue
- Top Products
- Revenue by Category
- Category Share (%)
- Top Customers

## SQL Skills Used
- JOIN
- GROUP BY
- ORDER BY
- SUM, COUNT, AVG
- Subqueries
- DATE_FORMAT
- IFNULL

## Files
- analysis_queries.sql
- ecommerce_analytics_main_script.sql

## Conclusion
This project demonstrates SQL skills applied to real business questions in e-commerce analytics.
